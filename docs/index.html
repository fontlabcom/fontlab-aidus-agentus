    Aidus Agentus for FontLab 9

    Aidus Agentus adds an AI chat dock inside FontLab 9. You can ask about the current glyph, inspect fonts and metrics, change spacing, or generate and run FontLab Python code. Responses stream into the dock. The selected AI provider receives your prompts and the tool results used by the agent; use a disposable font for your first editing experiments.

    The FontLab plugin runs in the host's Python 3.11/PythonQt environment. The AI brain runs in a separate Python 3.13+ process, using AgentPool 2.8.8. Installing AI libraries into FontLab's embedded Python is unnecessary.

    Read Configure Aidus Agentus for the short setup guide, architecture for the process/tool boundaries, and troubleshooting when something fails.

    Current acceptance

    The maintained host/brain split is retained. Active-editor/CurrentGlyph preservation, M1–M11, provider authentication, dock lifecycle, writer history/persistence and operational brain cutover still need their separately recorded acceptance. Legacy repository retirement is already verified; it does not qualify these workflows. These source/build previews do not establish native or published operation.
