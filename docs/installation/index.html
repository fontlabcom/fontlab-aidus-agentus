    Install the host and brain

    Install from this checkout

    You need FontLab 9, uv, and access to the FontLab Remopy wheel. Download that wheel first; replace the example wheel path below with its actual path. These commands run in a terminal at this repository's root.

    1. Install the lightweight host package into a dedicated folder:
    uv pip install --python 3.11 --target ~/.local/share/fontlab-aidus/host .
# Optional: required for the Enable FontLab MCP menu script.
uv pip install --python 3.11 --target ~/.local/share/fontlab-aidus/host --no-deps /path/to/fontlab_remopy-VERSION-py3-none-any.whl

    Remopy's in-FontLab enable helper needs only the host's fontlab module; its external MCP dependencies belong in the brain environment.

    1. In FontLab's Python console, make that host folder importable:
    import os, site
site.addsitedir(os.path.expanduser("~/.local/share/fontlab-aidus/host"))
import fontlab_aidus_agentus
print(fontlab_aidus_agentus.__version__)

    This adds the path for the current FontLab session. Repeat after restarting FontLab, or have your FontLab environment setup add it on each launch. The Scripts-menu folder link alone does not install the package or add this path.

    1. Create the separate brain environment and install the real AI dependencies:
    uv venv --python 3.13 ~/.local/share/fontlab-aidus/brain
uv pip install --python ~/.local/share/fontlab-aidus/brain/bin/python '.[brain]' /path/to/fontlab_remopy-VERSION-py3-none-any.whl

    Remopy is supplied explicitly because it may be absent from the package registry. If you maintain a sibling fontlab-remopy checkout, use its path instead of the wheel. On Windows use the environment's Scripts/python.exe wherever these examples use bin/python.

    1. Set python_exe and provider-key sources in the host JSON file as described in CONFIGURE.md. The bundled manifest uses OpenAI for the copilot/analyst and Anthropic for the coder. Configure both providers, or supply your own manifest.

    For an existing release, substitute its downloaded Aidus wheel for . and use '/path/to/fontlab_aidus_agentus-VERSION-py3-none-any.whl[brain]' for '.[brain]'. See RELEASE.md for v0.2.0 hashes and its historical verification. The new menu scripts require the current checkout's host package; v0.2.0 predates the installed launcher helpers. No PyPI installation is assumed.
